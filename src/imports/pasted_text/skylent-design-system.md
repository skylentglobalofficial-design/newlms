==================================================

- hover response

Three levels:

GLASS 01
Light glass

GLASS 02
Medium glass
For cards / panels.

GLASS 03
Deep glass
For important product surfaces / LMS.

→ GLASS SURFACE

→ ACTION

29. SCROLL EXPERIENCE
==================================================

The current scroll effect is good.

Standardize it.

Every major section:

Initial:
opacity 0
translateY 20-30px
blur 5-8px

Visible:
opacity 1
translateY 0
blur 0

Use:

IntersectionObserver

Animate major content groups, not every element.

Duration:

~450-650ms

Stagger:

small

No section should wait noticeably before becoming readable.

Respect:

prefers-reduced-motion

==================================================
30. PERFORMANCE
==================================================

Current website feels laggy.

Fix:

scroll performance
animation performance
glass rendering
tab switching
route transitions
large image loading
hidden component rendering

Rules:

No setInterval for scroll animations.

No continuous React state updates on scroll.

Use transform and opacity.

Lazy load below-fold images.

Lazy load heavy LMS/product previews.

Unmount or pause inactive interactive previews.

Reduce backdrop-filter area.

Use CSS transitions where possible.

Use IntersectionObserver.

Keep 60fps as the target.
