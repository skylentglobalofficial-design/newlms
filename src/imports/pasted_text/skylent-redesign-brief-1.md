- generic SaaS templates
- abstract technology graphics
- excessive grids
- square patterns
- random connecting lines
- glowing nodes
- floating geometric decoration
- meaningless micro-labels
- excessive gradients
- excessive neon effects
- generic AI illustrations

The website should communicate:

REAL EDUCATION
REAL PROGRAMS
REAL PEOPLE
REAL LEARNING
REAL CAREER PATHWAYS
REAL PRODUCT

3. OVERALL VISUAL SYSTEM
==================================================

Use ONE coherent Skylent visual identity.

Do NOT introduce dozens of unrelated colors.

The Skylent brand accent should remain consistent.

Use a restrained palette built around:
- Skylent brand accent
- deep dark tones
- off-white / neutral surfaces
- subtle atmospheric gradients

Use color intentionally.

Different areas of the ecosystem may have different ATMOSPHERES, but they must still belong to the same Skylent brand.

For example:

Education:
warm / human / optimistic

Skills:
energetic / focused / practical

Career OS:
technological / sophisticated / product-oriented

Institutions:
professional / enterprise / credible

Stories:
editorial / human

About:
visionary / sophisticated

Do not create completely different color systems for every page.

4. GLASS UI
==================================================

Use:
- translucent surfaces
- backdrop blur
- subtle borders
- layered depth
- soft shadows
- refined glass cards
- glass navigation

However:

DO NOT make every single section or element glass.

Use glass strategically alongside:

- photography

The contrast between glass and solid surfaces should create the premium feel.

Glass should feel sophisticated, not like a generic Web3 template.
