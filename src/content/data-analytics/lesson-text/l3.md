# Foundations check

This quiz is five scenario questions on lessons 1–2: what analytics is allowed to claim, how to rewrite a vague ask, aliases, and the Northwind net-revenue formula.

It is not a trivia contest about acronyms.

You must answer all five correctly to mark the lesson complete. After you submit, read the explanation even if you passed — the wording is the standard this course uses in later briefs.

**Not in this quiz:** Python, machine learning, job outcomes, certificates.
