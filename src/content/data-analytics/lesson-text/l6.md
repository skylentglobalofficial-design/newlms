# Spreadsheet analysis — Northwind Q1–Q2

Read the assignment brief in the workspace. You will clean `northwind_sales.csv` in Sheets or Excel, compute valid net revenue, and answer three commercial questions.

This LMS only stores **text**. Paste your cleaning log, tables, and recommendations. Link a view-only sheet if you have one.

There is no in-browser Excel runtime and no faculty grading in this pilot. Treat the rubric as how a reviewer *would* score a work sample.

When you are done, copy the same tables into Career OS → Projects yourself. The product does not create a portfolio entry automatically.
